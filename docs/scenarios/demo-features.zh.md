# Demo 功能全景分析与场景指南

本文档全面梳理 **qwen-audio-agent** 仓库中包含的各类 Demo、交互形态与垂直业务场景，分析其核心功能、架构协作方式及体验指引。

---

## 核心设计理念

项目所有 Demo 均围绕 **“全双工实时语音前台 + 异步后台 Agent”** 架构设计：

```
 ┌──────────────────────┐        ┌──────────────────────┐
 │   客户端 (Client)    │        │  后台 Agent (ACP/A2A) │
 │ Web / Desktop / TUI  │        │ OpenCode/OpenClaw/etc│
 └──────────┬───────────┘        └──────────▲───────────┘
            │                               │ (异步委派任务)
            ▼                               │
 ┌──────────────────────────────────────────┴───────────┐
 │                   Gateway 运行时                      │
 │   • 全双工实时语音通道 (DashScope/Omni/StepFun/etc)    │
 │   • 前台轻量级 MCP 工具 (就地查询/车控/即时操作)       │
 │   • 长期记忆与上下文融合 (Memory / Knowledge)          │
 └──────────────────────────────────────────────────────┘
```

- **持续在场**：交流不因后台任务、联网检索或工具调用而暂停；
- **边聊边办**：前台保持自然沟通与即时答复，耗时任务交由后台异步处理；
- **自然闭环**：后台任务执行完毕后，结果与产物自然回填至当前语音对话。

## 一、 通用交互端形态 Demo

项目开箱内置了三套面向通用场景的客户端交互 Demo：

| 客户端形态 | 体验命令 | 核心功能特性 |
| --- | --- | --- |
| **Web UI** | `npm run dev`<br>或 `qwenaudio webui` | • **全双工双向语音**：毫秒级实时流式对话、自动 VAD 检测与自然打断。<br>• **多模态输入**：支持文本输入、图片上传、摄像头拍照及实时视频画面输入。<br>• **后台任务卡片 (Task Cards)**：实时查看后台 Agent 执行阶段、工具调用日志与产物预览。<br>• **危险操作审批 (PermissionActions)**：支持敏感或涉款操作的交互式口头确认或按钮审批。<br>• **资料库与长期记忆 (Knowledge / Memory)**：可视化查看跨会话记忆与挂载的知识文档。 |
| **Desktop 桌面端** | `npm run desktop` | • **桌面常驻悬浮球 (Orb)**：支持 Fluid 动态流体、Goo 凝胶以及像素宠物 (Sprite Orb) 多种皮肤，兼容 Awesome Codex Pet 社区画廊。<br>• **状态联动动画**：实时映射“倾听”、“思考”、“发言”、“工具调用”、“后台忙碌”等状态。<br>• **离线语音唤醒**：内置“你好千问”离线唤醒词。<br>• **智能隐蔽与休眠**：空闲自动休眠并隐藏窗口，降低能耗与视觉干扰。 |
| **TUI 终端端** | `npm run tui`<br>或 `qwenaudio tui` | • **轻量化终端语音交互**：无需图形界面，在纯字符终端捕获麦克风与流式播报。<br>• **实时事件追踪**：以文本形式实时输出后台工具调用事件、生命周期与流转状态。 |

## 二、 垂直业务场景 Demo（`examples/`）

### 1. 智能座舱 Demo (`examples/smart-cockpit`)

针对未来智能座舱打造的车载语音交互参考实现，包含完整的 3D 车机界面、车载服务模拟器、座舱 Agent 与 Gateway。

- **多意图并发车控**：
  - 支持单句长文本中的多个独立控制意图（如：“*把后排车窗打开，空调调到二十二度，大灯打开，音乐音量调到六*”）。
  - 前台 MCP 并行下发各车控工具，执行完成后统一汇报结果。
- **高德多途经点导航**：
  - 支持自然语言规划复杂途经点路线（如：“*从这里出发，先去五常地铁站，再去城西银泰，然后去武林广场，最后到萧山人民广场*”）。
  - 有序解析 `waypoints` 与 `destination`，地图联动呈现真实路线。
- **屏幕触控静默感知**：
  - 用户在车机屏幕上手动调整设置（如点击切换“不走高速”），系统通过 GCP 事件静默同步上下文而不打断驾驶播报。当用户后续口头追问时，助手可无缝结合最新偏好回答。
- **前台闲聊与后台新闻检索并行**：
  - 用户发起新闻整理任务（“*帮我整理过去 24 小时 AI 领域的三条新闻*”），后台座舱 Agent 异步检索验证来源；在此期间前台语音交互不被中断，可继续调整空调或日常闲聊。
- **语音自建条件规则技能 (Custom Skills)**：
  - 用户可用自然语言创建车控自动化规则（如：“*创建一个低温提醒技能，当我把空调调到 19 度及以下，就提醒我注意保暖*”）。
  - 车载服务监听温度变化，在满足条件时触发通知并主动语音播报。
- **个性化记忆与附近推荐**：
  - 自动记住用户长效偏好（如“*喜欢吃烧烤但不能吃辣*”）；在推荐附近餐厅时自动召回偏好，给出真实 POI 并友情提示点餐少辣。

### 2. 智能客服 Demo (`examples/customer-service`)

基于零售与航空两大真实业务场景构建的智能客服体系，演示了前台对话与严肃后台业务事务的安全隔离。

- **高敏操作与只读查询隔离 (A2A 架构)**：
  - 身份核验（姓名/邮箱/会员号/证件后四位）与状态查询由前台 Realtime 快速响应；
  - 退票、改签、退货退款、修改收货地址等写操作委托给后台 Agent，通过同一业务数据源与 Policy 校验资格。
- **两阶段操作确认**：
  - 涉及资费与订单状态变更的写操作，后台 Agent 先输出“操作预览”；在客户口头确认或点击同意后才真正提交，防止误操作。
- **协同工作台矩阵**：
  - **客服工作台**：实时波形、转写对话流、订单卡片、工具审计明细；
  - **人工坐席接管台**：当业务规则冲突或超出权限时，自动携带完整上下文平滑转接人工；
  - **Policy 配置台**：提取业务规则候选，支持可视化规则决策表编辑、Diff 预览、备份与审计。

### 3. 多模态视觉 Demo (`examples/x-omni`)

基于 Qwen3.5-Omni 与 MiniCPM-o 的多模态实时交互实现。

- **多模态画面输入**：
  - 支持调用本地摄像头、桌面屏幕共享或静态图片上传，音画同步输入至模型。
- **按需识图与持续画面分析**：
  - 支持用户口头询问即时分析当前画面（“*看看我手里的书是什么？*”）。
- **主动视觉观察 (Visual Observation)**：
  - 用户可委托临时观察任务（如“*帮我盯住这锅水，水烧开了提醒我*”）；
  - 示例内置视觉观察调度器，具备超时退出、变化去重与主动打断播报能力。
- **WebRTC / WebSocket 双传输模式**：
  - 提供超低延迟的 WebRTC 媒体通道与标准 WebSocket 接入，兼具低延迟与兼容性。

---

### 4. WebRTC 客户端 Demo (`examples/webrtc`)

- **超低延迟直连**：
  - 使用浏览器原生 WebRTC 协议连接 Gateway，提供比 WebSocket 更优的抗弱网、防丢包与声学回声消除（AEC）效果。
  - 支持 Qwen Audio 及 Qwen Omni 多模态音视频交互。

---

### 5. AI Passport 硬件卡片 Demo (`examples/ai-passport`)

- **物理终端端云协同**：
  - 在 ESP32-C3 “千问语音豆”硬件卡片上运行麦克风采集、扬声器播放与角色状态动画。
- **局域网设备中继 (Device Relay)**：
  - 电脑端运行转发中继服务，将微型嵌入式设备通过局域网接入本地 Gateway，赋予硬件设备完整的复杂 Agent 任务处理能力。

---

### 6. VoiceMem 语音记忆 Demo (`examples/voicemem`)

- **跨会话长期记忆侧边服务 (Sidecar)**：
  - 独立运行的记忆提取与召回服务，自动分析多轮语音交流，提取结构化事实与用户习惯；
  - 在后续对话启动时，将长期记忆注入前台 Context，实现真正“认识你”的交互体验。

## 三、 快速体验指引

| 场景 Demo | 启动命令 | 所需配置与环境变量 |
| --- | --- | --- |
| **基础 Web UI** | `npm run dev` | 根目录配置 `QWEN_AUDIO_REALTIME_API_KEY` |
| **智能座舱** | `npm run example:smart-cockpit` | 高德地图 Key（用于真实 POI 与路线规划）+ 百炼 API Key |
| **智能客服** | `npm run example:customer-service` | 百炼 API Key（用于前台 Realtime 与后台 Agent） |
| **X-Omni 视觉** | `npm run example:x-omni` | `QWEN_AUDIO_REALTIME_MODEL=qwen3.5-omni-plus-realtime` |
| **WebRTC** | `npm run example:webrtc` | 支持 WebRTC 的网关配置 |
| **AI Passport** | `npm run example:ai-passport` | 局域网连接的 ESP32-C3 卡片设备 |
